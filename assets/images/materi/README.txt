PANDUAN MEMASUKKAN IKON GAMBAR BAB MATERI (AUTO-LOAD)
======================================================

Untuk menampilkan gambar kustom pada ikon di daftar Bab Materi Pembelajaran,
letakkan file gambar Anda di dalam folder ini dengan nama sebagai berikut:

1. Bab 1 — Pendahuluan                     -> icon-bab1.png
2. Bab 2 — Dasar Teori                     -> icon-bab2.png
3. Bab 3 — Etika dan Tanggung Jawab AI     -> icon-bab3.png
4. Bab 4 — Pengembangan Media dengan AI    -> icon-bab4.png
5. Bab 5 — Evaluasi dan Refleksi           -> icon-bab5.png

CARA PAKAI:
-----------
1. Salin file gambar Anda ke dalam folder ini: assets/images/materi/
2. Ubah nama file sesuai daftar di atas
3. Refresh browser — ikon langsung tampil otomatis!

ANTI-BROKEN IMAGE:
------------------
Jika file belum ada, ikon lama (SVG bawaan) tetap tampil sebagai fallback.
Tidak akan ada ikon rusak/pecah.

SARAN FORMAT:
-------------
- Format: .png dengan latar transparan (PNG-24)
- Resolusi ideal: 128x128px atau 256x256px
- Ukuran tampil di layar: 72x72px (auto-scale)
