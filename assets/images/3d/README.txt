PANDUAN MEMASUKKAN IKON 3D KUSTOM (AUTO-LOAD)
=================================================

Untuk menampilkan gambar / ikon 3D pada 4 kartu Eksplorasi E-Modul, Anda cukup meletakkan file gambar Anda di dalam folder ini (assets/images/3d/) dengan nama file sebagai berikut:

1. Kartu Materi Pembelajaran  -> namai file: icon-materi.png
2. Kartu Prompt Library       -> namai file: icon-prompt.png
3. Kartu Evaluasi             -> namai file: icon-evaluasi.png
4. Kartu Tentang              -> namai file: icon-tentang.png

KEUNGGULAN FITUR AUTO-LOAD INI:
-------------------------------
1. Tanpa Coding / Tanpa Edit HTML: Anda cukup drag-and-drop / salin file gambar Anda ke dalam folder ini, dan ganti namanya sesuai daftar di atas.
2. Anti-Broken Image: Jika file gambar belum Anda masukkan, sistem secara otomatis menyembunyikan elemen gambar dengan rapi tanpa menampilkan ikon gambar rusak (broken image X).
3. Langsung Muncul: Begitu file dimasukkan ke folder ini, silakan refresh browser Anda, dan ikon 3D langsung tampil memukau di bawah judul kartu!

Saran Desain:
- Gunakan format .png dengan latar belakang transparan (transparent background) agar efek 3D menyatu sempurna dengan kartu putih bersih.
- Ukuran resolusi ideal: 128x128px atau 256x256px (akan otomatis diukur menjadi 64x64px di layar agar super tajam/Retina display).
